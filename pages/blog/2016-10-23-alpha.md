The Panoptikum [alpha version](https://panoptikum.social) includes basic functionality.

The features are:

* Category tree with podcasts
* Podcasts with episodes
* Data available (from 2016-10-13)
  * 102 podcasts
  * 5750 episodes
  * 46 categories
* Parser: reads feeds and fills the database
* Podlove Webplayer
* Scan to subscribe via QR-code
* Responsive layout
* Response time < 25 ms
